Daily hole
BEFORE — one of 4 fixed built-ins (27–30) cycling
AFTER — "DEADWOOD TANGLE", freshly generated
 Root cause found: dailyIndexFor() always returned built-in hole 27–30 (4 holes cycling), so the same hole AND the same background repeated. Fixed: when the owner hasn't published, the daily now generates a fresh wacky single-green hole seeded by the day via genWacky — beatability-guarded (tests 4 seeds, falls back to a built-in only if all fail). Each day is a unique hole with a unique name → which also rotates the backdrop (St.hi=-1 → nameHash background). Verified 6 days: DEADWOOD TANGLE / CACTUS RIDGE / SCORPION DRIFT / COYOTE RECKONING / WIDOW'S PASS / FOOL'S GOLD GULCH — all different, all different bg index. 3 → 7 This also fixes the "same backgrounds repeat" complaint (different generated hole name → different painting each day). Loads in ~107ms incl. the beatability check. Could add more obstacle variety to genWacky.
